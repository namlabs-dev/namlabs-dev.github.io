裸のトリプル（Naked Triple）

3マス、3つの数字。ハウスの3マスの候補が同じ3つの数字だけなら、その数字は使い切り。ハウスのほかのマスからは消せます。

裸のトリプルとは

裸のペアにマスを1つ足した形です。行の3マスが、3・7・9にしかならないとします。1つが3、1つが7、1つが9。その行のほかのマスは、この数字にはなれません。

3マスがそれぞれ3つの候補を持つ必要はありません。{3, 9}、{7, 9}、{3, 7} のような組み合わせでも、3マス合わせて3つの数字だけなら成立します。

例題

1行目に、候補が {3, 9}、{7, 9}、{3, 7} の3マスがあります。合わせても3・7・9だけなので、この3つの数字はこの3マスのものです。

1行目のほかのマスから3・7・9を消します。R1C7 は {1, 3, 6, 7, 9} から {1, 6} に。R1C8 と R1C9 は {1, 2, 6} になり、次の手がぐっと近づきます。

裸のトリプルの見つけ方

  1. 空きが5マス以上のハウスに候補を書き込みます。
  2. 候補が2つか3つのマスを探します。
  3. 3マスの候補を合わせて、異なる数字がちょうど3つになる組を探します。
  4. その3つの数字を、ハウスのほかのマスから消します。
コツ：3マス合わせて本当に3つの数字だけか確かめましょう。4つ目の数字が1マスにでもあれば、トリプルではありません。

どんなときに使う？

ペアより数は少ないですが、ペアやポインティングペアが尽きた難問で出てきます。次はX-Wingに挑戦しましょう。
